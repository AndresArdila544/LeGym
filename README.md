# 🏋️‍♂️ Le Gym App – Concordia University

A mobile application designed for **Concordia University’s Le Gym**, built to improve student access to fitness resources through intuitive booking, real-time occupancy updates, fitness tracking, and integrated gym services.

📱 Developed using **React Native**, guided by the **Double Diamond Design Model** and **User-Centered Design (UCD)** principles.

---


## 🎯 Overview

Students at Concordia often face difficulties booking fitness classes, accessing gym resources, and managing schedules. This app centralizes all essential gym functions into one seamless interface.  

> Developed as part of **SOEN 6751 – Human Computer Interface Design**.

---

## ✨ Features

- 🔐 **User Registration & Profile Management**  
- 📅 **Class and Personal Trainer Booking System**  
- 📈 **Workout Logging and Progress Tracking**  
- 📊 **Live Gym Occupancy Monitoring**  
- 💬 **Chat Support with Gym Staff**  
- 🔐 **Locker Reservation and Expiry Alerts**  
- 💳 **Integrated Payment System**  
- 🔔 **Real-Time Notifications and Reminders**

---

## 🧭 Design Process

We followed the **Double Diamond Design Model**:
1. **Discover** – User research via reviews, competitor analysis, and problem identification  
2. **Define** – Personas, empathy maps, user flows, and task modeling  
3. **Develop** – Paper wireframes → Balsamiq prototypes → High-fidelity Figma UI  
4. **Deliver** – Full implementation using React Native and backend infrastructure with iterative refinement

All design decisions were rooted in **Jakob Nielsen’s 10 Usability Heuristics** to ensure accessibility, efficiency, and simplicity.
